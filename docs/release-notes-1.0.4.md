# Mogbot 1.0.4

## What's new in 1.0.4

- **Talk to agents inside a project** - click an agent in a project's sidebar and its chat opens where the terminal was; the sidebar is now Agents, Terminals and Dev server
- **Phone setup that explains itself** - the download code says it isn't the pairing code, Tailscale on your phone has a Not working? list (starting with the account), and pairing ends on a proper You're all set
- **Steadier phone link** - the phone reconnects at once when you come back to it, and both sides note why a link dropped
- **Keys only when needed** - logins only a key opens wait until a task needs them, with No, Chat about it or Yes, add it
- **Waiting for Grok** - the import walkthrough says whose move it is, at a calmer pace
- **Set up any engine** - Accounts & usage offers to set up an engine that isn't installed yet
- **Fewer Chrome windows** - agents reuse the empty tab and close their own
- **Polish** - Restart to update matches New agent, usage shows conversation length last, more room by the window buttons, the phone chat's conversation row moved into the ⋯ menu
