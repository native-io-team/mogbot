# Mogbot 1.0.11

## What's new in 1.0.11

- **Dictation learns your words** - Settings → Agents → Dictation keeps the names and terms dictation should always get right. Add one there, or just fix it: change the same dictated word twice before sending and it's added on its own, with Undo. This works for dictation from your phone too.
- **Every answer on the phone** - When a task asks with a menu (like Claude Code's Bypass Permissions warning), the phone now offers every answer, not only the highlighted one.
