# Mogbot 1.0.8

## What's new in 1.0.8

- **Clearer errors in the preview** - When your site's dev server fails, the preview shows the error in the app's own light or dark look, with Copy error and Send to agent, which puts it in the project's open agent chat for you to send.
- **Smoother chats** - Small fixes to sending and the message box on the Mac and phone.
