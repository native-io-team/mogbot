# Mogbot 1.0.3

## What's new in 1.0.3

- **Bring your agents first** - the Chief's first question is only whether you have agents somewhere else; "I'm starting fresh" asks what you want done, with ideas under it
- **The Chief talks, not pastes** - its first messages type themselves out
- **Grok, ChatGPT or Claude, by asking** - saying you have agents in another assistant starts the step-by-step walkthrough instead of trying to sign in to it
- **Move the window** - drag it by its top edge on every screen
- **Move to Applications** - opened from the installer disk, the app offers to move itself so updates can install
- **A clearer installer** - the download opens on the drag-into-Applications window
- **Polish** - no shadow above the Preview, Focus and Code tabs
