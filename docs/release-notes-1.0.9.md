# Mogbot 1.0.9

## What's new in 1.0.9

- **Cards wait for you** - An approval card no longer expires while you're away. Answer it later and the agent carries on with exactly what you allowed.
- **Picks up after a restart** - A turn cut off by a restart or update starts again by itself, without you typing Continue.
- **Extra Claude accounts sign in the official way** - Each extra account now signs in with Claude's own sign-in and Claude Code keeps the login. Accounts added before show Sign in again.
- **Wide tables scroll** - Tables wider than the chat scroll sideways in replies and result cards, on the computer and the phone.
- **Chat stays at the bottom** - A new card no longer leaves the chat scrolled above it.
- **Windows and Linux** - Your Chrome, remote access and the agent limit now work there too, and the approval rules understand Windows paths.
- **Settings and agent editing redesigned** - Settings and the Edit agent sheet are laid out in clear grouped cards.
- **Dictation with Bluetooth headphones** - Dictation uses the built-in mic when your headphones would switch to call quality, and keeps listening when the audio route changes.
