## Why this one

The north star is hard tasks made easy with less of the user's attention. Logins and "verify
it's you" walls are where hard tasks die (both teardowns say so; Grok Bot and Muse let you take
over from the phone). Today the agent asks well and then waits for the user to walk back to the
Mac, which can be hours. Closing it means a 2FA code typed on the phone in ten seconds and the
agent carrying on.

It fits in hours because the parts exist: the phone's sign-in screen already streams a window of
the agents' browser and sends taps and typing (`agents/phone_signin.rs`,
`mobile/src/app/signin.tsx`), and step in already holds the agent's tab so its tools can't read
it, wakes it on hand back and tells it only the address (`agent_browser/step_in.rs`). The work
is joining them: the phone drives the agent's own held tab instead of a fresh sign-in window,
with the same scope (the card's site and sign-in providers), the same "nothing typed is kept"
rules, the same one-answer gate, and hand back from either device.
